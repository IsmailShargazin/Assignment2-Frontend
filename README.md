# Assignment 2 — Flexbox and Grid

Sneakers Shop is a multi-page website created for Assignment 2. It demonstrates how CSS Flexbox and Grid can be used to build navigation, product cards, page layouts, an image gallery, and a portfolio.

## Pages

- **Task 0 — Navigation (`index.html`)**  
  A navigation bar with the website name on the left and links to all tasks on the right. The header uses Flexbox for alignment and spacing.

- **Task 1 — Product Cards (`task1.html`)**  
  Three sneaker cards arranged in a row with Flexbox. Each card contains an image, a product name, a description, and a button.

- **Task 2 — Page Layout (`task2.html`)**  
  A page built with CSS Grid areas: header, sidebar, main content, and footer.

- **Task 3 — Image Gallery (`task3.html`)**  
  A gallery of nine sneaker images arranged with CSS Grid. A caption appears when the user hovers over an image.

- **Task 4 — Portfolio (`task4.html`)**  
  A portfolio page combining both techniques. CSS Grid places the projects next to the sidebar, while Flexbox is used for navigation and content inside the project cards.

## How to Open

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Use the navigation menu to visit the other pages.

The website uses only HTML and CSS, so no additional packages or installation are required.

## Technologies Used

- HTML5 for page structure
- CSS Flexbox for navigation and cards
- CSS Grid for page layouts and the gallery
- CSS hover effects for interactive elements

## Project Goal

The goal of this assignment is to practise choosing between Flexbox and Grid: Flexbox arranges items within a row or card, while Grid organizes larger sections of a page.
